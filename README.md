# Orbit Post（試作）

Game Boy 風の 160×144・4階調画面で、コックピット視点の宇宙を飛ぶ配達ゲームの試作です。
3D はソフトウェアラスタライザで描いています。面ごとのフラットシェーディングの明るさを
4×4 のベイヤーディザで 4 階調に落としています。外部ライブラリは使っていません。

`index.html` をブラウザで開くだけで遊べます。

## 中身
- 解像度 160×144（3D 部分 160×120 ＋計器パネル 24 行）、表示は 30fps 固定
- Z バッファ付き三角形ラスタライザ、ニアクリップ、面法線による平行光源ライティング
- 惑星（地形ノイズで海と陸を塗り分けた低ポリ球）、月、回転するリング型ステーション、
  ソーラーパネル付きの前哨基地、小惑星帯（30 個）、恒星、背景の星、速度に応じて流れる宇宙塵
- ドッキング：速度 25 以下、扉に正対（約 37° 以内）、扉の中心に入ると成功
- 仕事のループ：受け取り → 配達 → 報酬。燃料切れや船体の大破でえい航され、50CR を払う
- パレット 4 種（GREEN / SILVER / NIGHT / AMBER）。一時停止中に左右キーで変更
- スマホ用のタッチボタン（十字キー・A・B・SELECT・START）

## 操作
| キー | ボタン | 動作 |
|---|---|---|
| 矢印 / WASD | 十字キー | 機首の上下・左右 |
| Z / J / Space | A | 加速 |
| X / K | B | 減速。B＋左右でロール |
| Shift | SELECT | 目標切り替え |
| Enter | START | 一時停止 |
